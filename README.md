# Lab12JUnit – Equipment Unit Testing

## Project Description
This project demonstrates unit testing in Java using Maven and JUnit 5. It tests the Equipment class and EquipmentService class.

## Technologies Used
- Java JDK 17
- Apache Maven 3.9.16
- JUnit Jupiter 5.10.2
- Visual Studio Code

## Requirements
- Java JDK 17 or later
- Apache Maven

## How to Run the Tests

1. Open the project folder in VS Code.
2. Open Git Bash in the project directory.
3. Run the following command:

```bash
mvn clean test
```

4. Check the test results in the terminal.
